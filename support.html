Support

Lucida is a photo browser and culling tool for the Mac. Your originals are never touched, and your marks live in Lucida's own library.

Get in touch

Email annfeng.daniel@gmail.com. Include the version number from Lucida › About Lucida, and a screenshot if it helps. If one particular photo is misbehaving, the file format and camera model will speed things up.

Frequently asked questions

Where are my ratings kept?
In Lucida's library, a single file inside the app's container. File › Back Up Library… copies it wherever you like, and File › Restore Library from Backup… brings it back.
Does Lucida modify my photos?
Never. It doesn't write a single byte to your RAW or JPEG files. Exports, collages, sidecars, and backups are all new files.
How do I get my marks into Lightroom?
File › Export Marks to XMP… writes sidecar files next to your photos. File › Export Marks for Lightroom… writes a file the bundled plug-in can import; install the plug-in from Settings › Export.
What does Lucida Pro include?
It's a one-time purchase that unlocks collage export and printing, the batch export extras, smart classification and people, smart albums, the Lightroom bridge, and place names. Everything else is free. Lucida › Lucida Pro… has the details, along with Restore Purchase.
What does it run on?
macOS 26 or later on Apple silicon.
